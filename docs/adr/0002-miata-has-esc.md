# The Miata has ESC although the real car never did

The real 2001 Miata (NB) was never sold with ESC. The Owner asked for ESC on their custom Miata in 3.0, so the Car file enables it, tuned to the car's own Bench understeer gradient, on by default and switchable off in tuning. The Car file marks it as an Owner addition, not stock equipment, so nobody "fixes" it back to the real car's spec.
