# The generated world is saved locally and reused

OSDS generates each Tile from open data, and some of that work is slow: de-shadowing the Aerial imagery, season colour, the Place recipe, and AI-made surface detail on the CPU. Instead of repeating it every drive, the game saves each Tile's generated results in a local World cache on the player's disk, keyed by Tile id and generator version, and reuses them the next time the car comes near; raw downloads are cached separately. A Tile looks the same every visit (stable per-Tile seeds), revisits load fast and work offline, and public services see each request once. When a generator changes, its version bump invalidates only that layer. We chose disk space over recomputation; the cache has a player-set size limit and evicts the least recently driven Tiles.
