**The first full Unreal Engine release.** Free, open-source driving on real US roads, built live from open map data. Windows 10/11.

## Download
- **Installer:** `SimCruise-2.0.0-windows-x64-setup.exe`. SmartScreen may warn (not code-signed): **More info > Run anyway**.
- **Portable:** `SimCruise-2.0.0-windows-x64.zip`. **Checksums:** `SimCruise-2.0.0-SHA256SUMS.txt`.

## What's new
- Go anywhere in the US: roads, terrain, buildings and trees built from open data as you drive.
- Cars calibrated to magazine tests, with a data-backed tyre (TMeasy), aligning torque, live air and wind.
- Live weather, sea and tide; traffic that stops at lights; USB wheels.
- Tune your car; the game remembers your choices.
