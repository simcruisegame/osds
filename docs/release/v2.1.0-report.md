# OSDS 2.1.0 release report (2026-11-17)

**In short:** two new cars (Mini Cooper S, 1987 Camaro IROC-Z), a drift handbrake, tunable tyre pressure, a truer Miata sound, CARLA art (signal poles, roadside grass and bushes by climate, brick and weathered concrete), tree species from the aerial photo. The owner called the release before the last QA round finished; open items are listed.

## Gate
- Benches for the new cars: CarTrack, StaticLoad, LiftOff, StepSteer, HandbrakeTurn (both), SineDwell (Mini): all pass; the Camaro's 0-60 and derived 70-0 are stated open items.
- Tree tests (`OSDS.World.Trees.*`): pass.
- Full `scripts\check.ps1`: not completed on the release commit (the first run timed out on the CARLA asset sweep, since limited to the shipped meshes; not rerun before the owner's go).
- QA robot: 23 runs at random and hard places (Mini, Camaro, lowered Miata, Corvette): 21 pass; Camaro spin on the Mackinac Bridge (Q21-1) and a tile-border jolt (Q21-2) are open (docs/release/bugs.md).
- `scripts\release.ps1`: RELEASE PACKAGE OK (self-test exit 0).

## Bugs fixed during the release
- Crash on quitting while an aerial photo was being AI-enhanced (exit code 3 in the smoke test; worker stopped on OnPreExit).
- No CARLA plants in the packaged game (the catalogue looked for a Content folder on disk).
- Grass on city sidewalks (verges now only on rural road edges).
