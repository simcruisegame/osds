## Power-capped runs (the "10 fps" of #120)
The same High run on Ocean Drive, same code, while another checkout was compiling:
seat 19.6 fps, GPU 49.3 ms, nvidia-smi average 22.3 W, 813 MHz, throttle reasons 0x24 (software power cap + thermal slowdown).
Run again with no compiler running: 53.3 fps, 17.9 ms, 57.9 W. The ratio is 2.6x, the 28 W factor in docs/team/performance-engineer.md.
A frame-rate number is only valid if nvidia-smi shows the clocks near their top while it runs (this laptop: 1200-1300 MHz under this load, 300 MHz idle, 2100 MHz max) and no build runs.
Harness fix (flag capped runs): #141.
