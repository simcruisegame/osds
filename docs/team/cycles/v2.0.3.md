### Release criteria for v2.0.3

1. (Owner) The entire game looks as real as we can make it, innovative, with AI, at any US place.
2. (Owner) The cars drive realistically in every way.
3. (Owner) The UI and all controls work with the Xbox controller.
4. Any US place: random places pass the same test as hero places; each method has a fallback; no hand fixes.
5. No obvious fault from the driver's seat (bridges, floating or sunk objects, gaps, lips, pop, flicker, stuck car); each fault the owner reported is fixed and shown in frames.
6. Proof against the real thing: each part in the grade table has a game frame next to a real photo; no part stays at D; each part goes up one grade or more.
7. Smooth: 60 fps at Ultra on the owner's laptop; input delay under 96 ms; each new detail within the GPU budget rule (0.3 ms p95, an off switch).
8. Stable: no crash, no hang, fast start, clean quit, tested installer.
9. Sound agrees with each car and the road.
10. Legal and clean: licences and credits recorded, no owner name, README and screenshots current.
