# Recorded tiles for tests

Two zoom-16 tile documents from the map helper's `tile` command (2026-11-14), kept as they were for
`SimCruise.World.JunctionSteps`: the junctions where the v2.0.3 release test found road steps.

- `17916_25409.json`: Welch, WV (Court Street where two driveways and Hobart Street join).
- `17429_26202.json`: Doraville, GA (motorway ramp merges, three bridges).

Map data (c) OpenStreetMap contributors, ODbL 1.0; heights USGS 3DEP (public domain). See
`docs/data-sources.md` and `licenses/`.
